# Ordre des passes — ne pas sauter

Sans sol vrai, le ciel est un poster. Sans lieux vrais, les villes flottent.

```
PASSE A — .carte → sol visible + pieds + ID biome + lieux + marche
   (cahier-dark-fps / cahier-grok/)
        ↓
PASSE B — ciel Dark (trou noir, planètes, nuages)  ← doc 03
        ↓
PASSE C — masses 3D + villes DESSUS/DESSOUS        ← doc 04
        ↓
PASSE D — social dehors (barks, mémoire, gardes) + combat déjà là
```

**Maintenant, Claude : uniquement A**, sauf si A est déjà **vue** (bouton Ouvrir une carte, 3 tests, mesh = pieds).

Si A n’est pas faite, **interdire B/C/D**. Le ciel sur l’ancien `relief.png` = on repeint un mensonge.

Combat (fourreau) peut vivre **en parallèle** dans l’hôtel. Ce n’est pas un prérequis du ciel. Ne pas les fusionner dans la même passe.
