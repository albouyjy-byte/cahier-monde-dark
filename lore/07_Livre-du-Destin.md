# Le Livre du Destin

Source Drive : [Le Livre du Destin](https://docs.google.com/document/d/1xglRPTxSALpTW9j0x0VdIUECdzIWi6wR4fAcU-NCRwY/edit)

C’est un **livre dont vous êtes le héros** (paragraphes-lieux, languettes, dés, roues).

## Ce n’est pas le FPS

**Ne pas** le recoder dans `hotel-brume-ecarlate.html`.  
Le FPS a déjà : marche, `Barks`, paliers, fourreau, `.carte`.

Utile à **lire** (ambiance, pas mécaniques) :

- Poèmes et chants = voix / barks (Carrefour le dit aussi)
- Pitié des ennemis, boss qui parlent (déjà dans l’esprit hôtel / combat)
- Landes = **Larzac / Millau**, pastoral, boucs, caves à fromage, transhumance
- Carnet de routes du héros (encyclopédie qui se remplit — plus tard)
- Fin philosophique possible : Strige casse la Bibliothèque / IA (Codex) — **pas une cinématique de passe A**

Musique évoquée côté livre : oppression, mélancolie (Exanima *Underworld Sorrows*). Côté Carrefour : dungeon synth / synthwave dark.

Combat du **livre** (1D6, languette vie 3 crans) ≠ combat du **FPS** (paliers, jeton, fourreau). On ne mélange pas.
