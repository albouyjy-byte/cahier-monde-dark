# Deux jeux, un moteur

On ne clone pas l’hôtel pour en faire un Dark. On **ouvre le dehors**.

| | Hôtel (enquête) | Géode (Dark) |
|---|---|---|
| Où | Intérieur, pièces, Contact | Dehors, carte peinte, biomes |
| Lien | Relation, Perception, souvenirs | Les **mêmes** outils, sur d’autres PNJ |
| Combat | Exception (fourreau, règle 11 : on n’achève pas) | Le cœur. Paliers, jeton, armes fantasy |
| Armes | Verre, livre, assiette en main. Pas d’épée « réelle » sauf test | Lames, masses, morning star — Dark |
| Priorité JY **maintenant** | Mise de côté (le moteur reste) | Carte + ciel + masses + villes |

Le HTML `hotel-brume-ecarlate.html` **reste** le jeu. Le Dark n’est pas un second dépôt de code.

Social Elden Ring = **l’hôtel transplanté dehors** : un PNJ se souvient du coup, parle, fuit, aide. Pas un open world muet.
